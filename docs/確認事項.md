## 決まったこと
- 戦い方はコマンドを選ぶターン制（2026-10-31）
- 戦うのは仲間にしたモンスター（2026-10-31）
- 流れは 町 → 受付でクエストを選ぶ → フィールド（ボス1・雑魚5）（2026-10-31）
- フィールドはスティック操作。主人公はいつも画面のまん中（2026-10-31）
- 最初の仲間は、隣の村の村長さんから借りる。襲われた村を守るチュートリアルから始まる（2026-10-31）
- 買い物〜村長さんまでは導入ムービーにする（2026-10-31）
- 最初のモンスターは1体だけ。チュートリアルのあともらえる（2026-10-31）
- 襲われるのは主人公が住んでいない別の町。買い物先はいつものショッピングモール（2026-10-31）
- チュートリアルの敵は雑魚2体＋ボス1体。ボスはモンスター取り網［小］で捕まえられる（2026-10-31）
- ムービーは短い動くアニメを紙芝居のようにつなげる（2026-10-31）
- チュートリアルのボスは必ず捕まる。捕まえ方のコツ（弱いほど・弱らせるほど捕まえやすい）をチュートリアルで教える（2026-10-31）
- 取り網は［小］［中］［大］。使うとなくなる（2026-10-31）
- ふだんのクエストでも、弱らせればボス・雑魚ともだいたい捕まえられる（2026-10-31）
- 取り網は大きさ専用。［小］は小さいモンスター、［中］は中くらい、［大］は大きいモンスターだけ（2026-10-31）
- どうぐやで取り網［小］［中］［大］を売る。トルピーのクエストの報酬でコインをもらう（2026-10-31）
- 戦闘に「こうたい」。連れていけるのは3体まで。裏市場のモンスター きょうしつで選ぶ（2026-10-31）
- レンとの素材集めは「特別クエスト」。モンスターは出ない。広いマップに素材を離して置き、木や岩の裏にも隠す（2026-10-31）
- モンスター・名前・世界観はオリジナルで作る。既存作品の名前やデザインは使わない（2026-10-31）
- 出す先はまずウェブ。GitHub に載せて個人で遊ぶ（2026-10-31）
- 絵などの出力は Codex に頼ってよい。agy も動けば使ってよい（2026-10-31）
- フォルダはごうのすけゲームと別（2026-10-31）
- 対象は子ども（2026-10-31）
