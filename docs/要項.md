# 要項（取りまとめ）

最終更新: 2026-10-31

## 基本
- 子どもが自分で開発して、自分で遊ぶゲーム
- 対象: 子ども
- ごうのすけゲームとは別のプロジェクト

## ゲームの内容
- イメージ：モンスターを仲間にして育てる遊びと、大きなモンスターを狩って素材で装備を作る遊びを合わせたもの（本人の言葉では「ポケモン × モンハン」）
- モンスター・名前・道具・世界観はすべてオリジナルで作る。既存作品の名前・キャラクター・デザイン・用語は使わない（GitHub で公開するため）

### 戦い
- コマンドを選ぶターン制
- 戦うのは仲間にしたモンスター（主人公は戦わない）

### はじまり
#### 導入ムービー
- 作り方：短い「絵が動くアニメ」を、紙芝居のように場面ごとにつなげる

1. 主人公が、ふだんよく行くショッピングモールへ買い物に出かけている
2. 主人公が住んでいない、別の町がモンスターに襲われているのを見て、助けたいと思う
3. その町の隣の村へ行くと、その村には人と仲よしのモンスターがいると聞く
4. 村長さんが「とりあえずこのモンスターを使って、隣の村を守ってきてやれ」と言って、
   - 最初の仲間モンスター（1体に決まっている。選ぶことはできない）
   - 「モンスター取り網［小］」
   を渡してくれる

#### チュートリアル
- 襲われた町で、雑魚2体 → ボス1体 の順に戦う（ここで戦い方を覚える）
- ボスはモンスター取り網［小］で捕まえられる。画面で「捕まえよう」とはっきり伝える
- チュートリアルのボスは、取り網を使えば**必ず**捕まる
- チュートリアルの中で、捕まえ方のコツを教える
  - 弱いモンスターほど捕まえやすい
  - 強いモンスターでも、弱らせればどんなモンスターでも捕まえやすくなる
- チュートリアルが終わると、村長さんのモンスターはそのまま主人公のものになる（もらえる）

### モンスターを捕まえる
- ふだんのクエストでも、ボス・雑魚とも、弱らせればだいたい捕まえられる
- 捕まえやすさは「モンスターの強さ」と「どれだけ弱らせたか」で決まる
- 道具：モンスター取り網［小］［中］［大］
  - 大きさごとに専用：［小］は小さいモンスター、［中］は中くらいのモンスター、［大］は大きいモンスターだけ捕まえられる
  - チュートリアルのボスは小さいモンスターなので［小］で捕まる
  - ［中］［大］はあとで作る
  - 使うとなくなる
  - 手に入れる場所は後で決める

#### 裏市場ムービー（チュートリアルのあと）
1. ボスをやっつけた（捕まえた）主人公に、村長さんが「きみには さいのうが ある」と言う
2. 村長さんが「裏市場（うらいちば）」へ連れていってくれる。裏市場はクエストを受ける場所
3. 裏市場の先輩「レン」が、裏市場を紹介してくれる
4. レンが、主人公が装備をつけていないことに気づき、素材をくれる
5. 裏市場の鍛冶屋で、その素材から防具と武器を作る
6. 主人公が装備すると、仲間モンスター全員のステータスが少し上がる
7. でも装備はまだあまり強くないので、レンと一緒に素材を集めに行くことにする

#### 裏市場（ムービーのあと遊べる場所）
- クエスト受付をタップすると、クエストを受けられる
- いまあるクエストは、レンとの「素材集め」だけ。受付では「特別クエスト」と表示する

#### 特別クエスト「素材集め」
- モンスターは出ない
- 村を守ったときのフィールドのような、広いマップ（さらに広め）
- 素材はあちこちに離して置く（固まっていると簡単に集まってしまうため）
- 木・岩・しげみなどの裏に隠した素材もある

#### かじやで強化
- 新しく作るには素材がたくさん必要なので、武器と防具の2つとも「強化」する
- レンが強化のしかたを教え、その通りにボタンを押す

#### 次のクエスト
- 強化のあと、受付の人が「次のクエストがあります」と言う。主人公はクエストを受けて現場へ向かう
- 敵は本人が描いた「トルピー」と「イエロール」（原画は 参考資料/）

### ゲームの流れ（チュートリアルのあと）
1. **町**：主人公の住む町。クエストを受ける場所（受付）がある
2. **クエストを受ける**：受付で戦いたい相手（ボス）を選ぶ
3. **フィールドへ出る**：オープンワールドのフィールドへ行く
4. **フィールド**：ボス1体と雑魚モンスター5体がいる

### フィールドの操作と画面
- 画面上のスティック（バーチャルスティック）で主人公を動かす
- 主人公はいつも画面のまん中。スティックの動きに合わせて背景が動く（カメラが主人公についていく）

## 試作 v0.1 で仮に決めたこと（変えてよい）
- タイトル：みんなの モントモ（2026-10-31 本人が決定）
- 最初の仲間：ポムル（みどりの まるい モンスター。頭に双葉）
- ざこ：イガボン（とげとげの くりのような モンスター）
- チュートリアルのボス：ドンゴラ（いわを せおった 小さな トカゲ）
- ポムルの わざ：ころころアタック（かならず あたる）／はっぱシュート（つよいが はずれることも）／げんきチャージ（回復）
- 主人公の名前は最初に入力（空なら「ソラ」）
- チュートリアルでは負けない（ポムルが倒れそうになると村長の声で回復）。にげられない
- ざこ2体を倒すまで、ボスのまわりは「くろい けむり」で近づけない
- ざこ戦では取り網を使えない（「ボスの ために とっておこう」と出る）
- 村長のセリフは「となりの まちを まもってきて やれ」（襲われているのは町なので「村」を「町」にそろえた）
- 裏市場ムービーは7場面。ボスは「倒した」ではなく「つかまえた」にそろえた
- レン：ゴーグルとオレンジのマフラー、背中に取り網。自分のことは「レン」と名前で言う（「ぼく／わたし」は使っていない）
- もらう素材：てつの かけら ×3、じょうぶな かわ ×2
- 作る装備：かけだしの よろい（防具）、かけだしの こんぼう（武器）。装備後は主人公の絵にも反映
- 装備の効果：仲間モンスター全員に HP +5、こうげき +1、ぼうぎょ +1
- 裏市場の画面：どうぐや（準備中）・クエスト うけつけ・かじや の3つの店。受付をタップ→赤いリボン「★とくべつ★」つきの「とくべつクエスト「そざいあつめ」」→「うけますか？ はい／いいえ」→出発
- 素材集めのマップ「しずかな もり」：3000×2400（村を守った町は1800×1400）。池・岩6つ・しげみ5つ・木がたくさん
- 素材は8こ（てつの かけら3・じょうぶな つる3・きらきら いし2）。いちばん近い2つでも約600離れている。8こ中5こは隠れている（木の裏2・岩の裏1・しげみの中2）。近くを歩くと自動で拾う
- 隠れた素材はときどき小さく光る（ヒント）。右上の「レンに きく」で、いちばん近い素材の方向に矢印が出て、「○○の あたりが あやしいよ」と教えてくれる。45秒見つからないとレンが自分から教える
- レンは主人公のうしろをついてくる（戦わない）
- 8こ集めると裏市場に戻り「とくべつクエスト クリア！」→「かじやで そうびを きょうか する」
- 強化：レン「まずは ぶきの きょうかボタンを おしてみて」→ ぶき（てつ2・きらきらいし1）→ ぼうぐ（つる3・てつ1・きらきらいし1）。ちょうど集めた8こを使い切る。順番を間違えるとレンが教える
- 強化の効果：こんぼう Lv2（こうげき +1）、よろい Lv2（ぼうぎょ +1・HP +5）。仲間みんなで HP+10・こうげき+2・ぼうぎょ+2 になる
- 次のクエスト名「トルピーを さがせ」（★2）。受付で取り網［小］を3こもらう
- 現場は「そうげん」（2400×1900）。イエロール5体（ざこ）、いちばん奥にボスのトルピー。トルピーを倒すか捕まえたらクリア
- トルピー：HP60 Lv6、わざ「ギザギザつばさ」「やじるしストライク」「キバキバかみつき」。イエロール：HP24 Lv3、わざ「ぐるぐるローリング」「こしに てを あてて タックル」（わざの名前はこちらで仮に付けた）
- ふつうのクエストでは、取り網はだれにでも使える。成功しやすさ＝もとの捕まえやすさ（イエロール35%・トルピー15%）＋弱らせたぶん（最大+75%）。失敗すると「あみから にげだした！」。逃げることもできる。ポムルが倒れそうになるとレンが薬で回復（負けて終わりにはしない）
- クリアすると受付で報酬 500コイン。裏市場で「クエスト クリア！ ほうしゅう・なかまに なった：〇〇」

#### じぶんと レンの いえ・あさと よる（v0.9）
- うらいちばの いちばん みぎ（スワイプした さき）に「〇〇と レンの いえ」。ふたりは いっしょに くらしている
- いえの なかに ベッドと たな。たなには とりあみ［小］［中］［大］・てつ・つる・きらきら いし を しまう／だす（1こずつ）。たなに しまった ものは たたかいでは つかえない
- ベッドで ねると あさ。そこから 5ふんで、あさ → ひる → ゆうがた → よる と すこしずつ かわる。よるに なったら ねるまで よるの まま。さいしょは よる
- うらいちばの そら・かべ、いえの まど、もり・そうげんの くらさが じかんで かわる。がめんの ひだりうえに「あさ／ひる／ゆうがた／よる」

#### まおうの しゅうげき（v0.9）
- トルピーの クエストの あと、モンスター きょうしつを とじると はじまる（さきに どうぐやで あみを かえるよう、やじるしは どうぐや → きょうしつ の じゅん）
- ムービー6ばめん：くらく なる → うきしまの まおう →「わしは まおう じゃ」→ たいほう → ふたりが よける →「ほう…、よけたか」→ てしたを おとす →「もう すこし つよく なったら、あいてを して やる」→ かえる → うけつけの ひとが とりあみ［中］を 1こ くれる
- そのあと うらいちばで ざこ「ポコボム」3びき → ボス「ゴロガンテ」の じゅんに たたかう。ここでは にげられない
- ポコボム：かぜ・小さい（［小］で つかまる）。ゴロガンテ：いわ・中くらい（［中］で つかまる）。なまえ・みためは かり（本人の えで かきなおせる）
- ぜんぶ たおす／つかまえると「まおうの しゅうげきを しのいだ！」

#### わざの ぞくせい（v0.7）
- ぞくせいは5つ：ふつう・くさ・いわ・かぜ・ひかり。くさ→いわ→かぜ→くさ の じゃんけん（つよい側は ダメージ1.5倍、よわい側は 約0.67倍）。ひかり と ふつう は どれにも ふつう
- モンスターの ぞくせい：ポムル・イガボン＝くさ、ドンゴラ＝いわ、トルピー＝かぜ、イエロール＝ひかり（こちらで仮に決めた）
- わざの ボタンに「ぞくせいの ふだ・なまえ・いりょく・めいちゅう（%）・その ほかの こうか」と、いまの あいてに よく きくなら「◎よくきく」、きかないなら「△いまいち」を出す
- その ほかの こうか：「つぎの ダメージ はんぶん」（ドンゴラ：かたい いわの かまえ）、「あいての こうげき ダウン」（トルピー：キバキバかみつき、イエロール：ピカッと にらめっこ）、HP かいふく
- HP の わくにも ぞくせいの ふだを出す。こうたいの ボタンにも ぞくせいを出す
- チュートリアルの ボス戦で、村長が「ドンゴラは いわ。くさの わざが よく きく」と教える

#### お金・どうぐや（v0.5）
- お金の名前は「コイン」。いまはトルピーのクエストの報酬（500コイン）だけで手に入る
- どうぐやで とりあみ［小］100コイン・［中］300コイン・［大］800コイン を売っている（値段はこちらで決めた）
- 網は大きさ専用。戦闘の「とりあみ」で大きさを選ぶ。合わない大きさを選ぶと「〇〇は △△ モンスターだから ［小］を つかおう」と教え、網は減らない
- いまいるモンスターはみんな小さい（［中］［大］で捕まえる相手はこれから）

#### 仲間・交代・モンスター きょうしつ（v0.5）
- 戦闘のボタンは「わざ・とりあみ・こうたい・にげる」
- 連れていけるのは3体まで。先頭の1体から戦いが始まる
- 「こうたい」で、連れてきたほかの仲間と入れかわる（自分から交代すると相手の番になる）。倒れた仲間がいたら、ほかの元気な仲間と交代。全員倒れそうになるとレンが薬で全員回復
- 仲間ごとに HP と わざ が違う（ポムル・ドンゴラ・トルピー・イエロール）。わざの名前と強さはこちらで仮に決めた
- 裏市場を横に伸ばして4けん目に「モンスター きょうしつ」。横にドラッグするか ◀ ▶ で移動。ここで連れていく仲間（3体まで）を選ぶ。上の3つのわく＝連れていく仲間（いちばん左が せんとう）、下＝持っている全部。タップで入れる・外す。最後の1体は外せない
- 捕まえた仲間は、連れていく枠があいていれば自動で入る
